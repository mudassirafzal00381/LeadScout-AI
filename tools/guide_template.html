LeadScout AI - Installation Guide

Find local businesses that need your services - free, on your own computer.

✓What you need

  • A Windows 10 or 11 PC (64-bit) with an internet connection.
  • Google Chrome or Microsoft Edge (Edge comes with Windows, so this is almost always already there).
  • About 1 GB of free disk space and 10 minutes for the one-time setup.

1Unzip the file

  1. Right-click LeadScout-AI.zip → Properties. If you see an Unblock checkbox at the bottom, tick it and click OK. (This prevents Windows warnings in the next steps.)
  2. Right-click the zip → Extract All… → in the box, type C:\ → Extract. This creates the folder C:\LeadScout AI.
Use a short location like C:\LeadScout AI: Windows can't handle the installation inside very long folder paths. Don't run it from inside the zip, and don't use C:\Program Files.

2Install (one time only)

  1. Open the extracted LeadScout AI folder and double-click Install LeadScout AI.bat.
  2. If Windows shows "Windows protected your PC", click More info → Run anyway.
  3. A black window opens and installs everything. Wait 5-10 minutes until it says Setup complete! If Python isn't on the PC yet, the installer adds the official Python 3.11 automatically.
  4. At the end it checks the PC. All lines should say [OK].
  5. Press Y to start LeadScout AI straight away.
A LeadScout AI icon with the logo is added to your desktop. That's all you need from now on.

3Start LeadScout AI (every time)

  1. Double-click the LeadScout AI icon on your desktop.
  2. A small black window opens and your browser opens LeadScout AI automatically at http://localhost:8501.
  3. Keep the black window open while you work. When you're done, close the browser tab and then the black window.
LeadScout AI runs entirely on your computer. Nobody else can open it, and your results stay on your PC.

4Find leads - the workflow

✍️ Describe→🚀 Find Leads→📡 Wait 5-8 min→📊 Review→⬇️ Download Excel→📞 Contact
  1. Type what you want in plain English in the search box, for example:
    restaurants in Lahore that need a website
    salons in Karachi without social media
    gyms in Islamabad that need a website and have a phone number
    Or click one of the example buttons under the box.
  2. Check the Understood as line (business type · city · what they're missing). Reword your request if it's wrong.
  3. Click 🚀 Find Leads. A radar animation and a live progress panel show what's happening. One business type takes about 5-8 minutes, because LeadScout also looks up a phone number for every business.
  4. Review the results: summary numbers, Top opportunities (the best leads you can call), and the full table. Click any column title to sort.
  5. Click ⬇️ Download Excel File. A copy is also saved in the output folder inside the LeadScout AI folder.
  6. Contact the businesses and offer your services!

5Tips for better results

  • Works in any country. Always name a city (or town / area): plumbers in London, restaurants in New York, dentists in Dubai, salons in Karachi. A whole country or state ("USA", "Texas") is too large - LeadScout will ask you to name a city.
  • If a city name exists in several countries, add the country or state: Springfield, Illinois, Hyderabad, Pakistan.
  • Any type of business works - common ones (restaurants, salons, plumbers, dentists, roofers…) are recognised automatically, and anything else ("solar panel installers in Austin") is searched as written.
  • Phone numbers are shown in international format for the country you search (e.g. +1 USA, +44 UK, +971 UAE, +92 Pakistan).
  • Advanced Options lets you pick a category or location from a list, type what the leads should be missing (e.g. no website, no social media), and set how many results to collect.
  • Leaving out the business type ("businesses in Lahore that need a website") searches 12 common types - this takes 30-60 minutes.
  • Avoid running very large searches many times in a row - Google may slow you down for a while.

6Understanding the results

ItemMeaning
Red cellKey gap: no phone number, or no real website.
Orange cellOther missing info: email, Facebook, Instagram, LinkedIn, address - or a website that doesn't load.
Lead Score (0-100)Higher = more missing = more services you can offer. No website +40, no social media +30, no phone +30.
Phone numbersEvery lead has a phone number. Businesses found without one are looked up on Google Maps; any that still have no number are left out (the results page tells you how many).
EmailFound on the business's website or its Contact page. Leads with an email are listed before similar leads without one. Businesses with no website usually have no public email.
Top opportunitiesThe best leads to contact first.

?Troubleshooting

ProblemWhat to do
"Windows protected your PC"Click More info → Run anyway. Next time, unblock the zip first (step 1).
Setup says Python couldn't be installedInstall Python 3.11 from python.org (tick "Add python.exe to PATH"), then run Install LeadScout AI.bat again.
Setup stopped with an errorCheck the internet connection and run Install LeadScout AI.bat again - it continues where it stopped.
"This folder's location is too long for Windows"Move the whole LeadScout AI folder to C:\LeadScout AI and run the installer again from there.
Browser didn't openOpen http://localhost:8501 yourself while the black window is open.
"Google Maps could not start (Windows blocked a component)"Windows security was checking a file. Close LeadScout AI (the black window) and start it again from the desktop icon.
"is a whole country - too large" / "Location not found"Name a city, and add the country if the name is ambiguous, e.g. Paris, France.
Google Maps found 0 businessesGoogle may be limiting searches. Wait an hour, or use smaller searches. OpenStreetMap results still work.
Anything elseError details are saved in the logs folder. Send the latest log file to your LeadScout AI provider.
